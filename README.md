# DATA STRUCTURE AND ALGORITHM

## Repository Structure

This repository contains various implementations of data structures and algorithms in multiple programming languages. The following is an overview of the structure and contents of this repository:

```
DATA-STRUCTURE-AND-ALGORITHM/
├── README.md
├── algorithms/
│   ├── sorting/
│   │   ├── bubble_sort.py
│   │   ├── quick_sort.py
│   │   └── merge_sort.py
│   ├── searching/
│   │   ├── binary_search.py
│   │   └── linear_search.py
├── data_structures/
│   ├── arrays/
│   │   ├── dynamic_array.py
│   │   └── static_array.py
│   ├── linked_lists/
│   │   ├── singly_linked_list.py
│   │   └── doubly_linked_list.py
│   ├── trees/
│   │   ├── binary_tree.py
│   │   └── binary_search_tree.py
│   └── graphs/
│       ├── graph_representation.py
│       └── graph_traversal.py
└── tests/
    ├── test_sorting.py
    ├── test_searching.py
    └── test_data_structures.py
```

## Contents

1. **algorithms/**  
   This directory contains various sorting and searching algorithms. Each algorithm is implemented in a separate file for better modularity.
   - **sorting/**  
     - *bubble_sort.py*: Implementation of the bubble sort algorithm.  
     - *quick_sort.py*: Implementation of the quick sort algorithm.  
     - *merge_sort.py*: Implementation of the merge sort algorithm.
   - **searching/**  
     - *binary_search.py*: Implementation of binary search.  
     - *linear_search.py*: Implementation of linear search.

2. **data_structures/**  
   This directory contains implementations of various data structures. Each design pattern is separated into its own subdirectory.
   - **arrays/**  
     - *dynamic_array.py*: Implementation of a dynamic array.  
     - *static_array.py*: Implementation of a static array.
   - **linked_lists/**  
     - *singly_linked_list.py*: Implementation of a singly linked list.  
     - *doubly_linked_list.py*: Implementation of a doubly linked list.
   - **trees/**  
     - *binary_tree.py*: Implementation of a basic binary tree.  
     - *binary_search_tree.py*: Implementation of a binary search tree.
   - **graphs/**  
     - *graph_representation.py*: Various ways to represent graphs.  
     - *graph_traversal.py*: Implementation of graph traversal algorithms (DFS, BFS).

3. **tests/**  
   This directory includes tests for the algorithms and data structures implemented to ensure their correctness and efficiency.
   - *test_sorting.py*: Unit tests for sorting algorithms.
   - *test_searching.py*: Unit tests for searching algorithms.
   - *test_data_structures.py*: Unit tests for data structures.
